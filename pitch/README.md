# Pitch: National Founder Cup 2026

Материалы выступления: дека на русском, демо-видео и код, которым это записано.

## Формат — 3 минуты

| | что | сколько |
|---|---|---|
| Слайды 1–7 | речь по [script-ru.md](script-ru.md) | ~90 сек |
| Слайд 8 | «Откуда цифры» — не проговаривается, backup для вопросов жюри | — |
| Слайд 9 | запуск `demo/whitebox-demo.mp4` | 96 сек |

## Что где

```
deck/    WhiteBoxAI-NFC-2026.pptx   для выступления (в слайд 9 вставляется видео)
         WhiteBoxAI-NFC-2026.pdf    для рассылки жюри
         build-deck.mjs             сборка деки (pptxgenjs)
         render-assets.mjs          рендер белого куба из геометрии продукта
demo/    whitebox-demo.mp4          96 сек, 1080p H.264, без звука и титров
         recorder/                  скрипты записи и монтажа
```

Шрифты деки — Bahnschrift SemiBold / Segoe UI / Consolas: всё штатное для Windows,
на чужой машине ничего не поедет.

## Демо-видео

Три части, снятые отдельно и сшитые кросс-фейдами: работодатель создаёт вакансию →
кандидат проходит интервью → рекрутер читает доказательства и принимает решение.

Ничего не инсценировано: вакансию пишет модель, интервью и расшифровка настоящие,
оценка получена в продукте. Единственная подмена — микрофон: вместо живой речи в
браузер подаётся синтезированная дорожка (`recorder/media-inject.mjs`), потому что
итоговое видео немое и отыгрывать четыре ответа под запись незачем. Камера при этом
настоящая.

Запись: `rec-part1.mjs`, `rec-part2.mjs`, `rec-part3.mjs` — каждый пишет свой кусок
и `beats.json` с таймкодами состояний. Монтаж: `edit.mjs` режет по этим таймкодам,
ускоряет паузы (генерация вакансии, загрузка, расшифровка) и сшивает в один файл.

Требуется запущенное приложение на `127.0.0.1:3100` и `OPENAI_API_KEY` в окружении.

## Цифры

Внешние данные на слайдах подписаны источником (БНС РК, SHRM, EU AI Act), расчёт
экономии помечен как модель — он строится на наших допущениях о длительности этапов
и проверяется на пилотах, а не выдаётся за факт. Полный список — слайд 8.
